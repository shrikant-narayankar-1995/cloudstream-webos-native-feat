# Plugin compatibility

Status 2026-10-19. "Host" = Alpine art_standalone on x86_64 (container, and relocated on Ubuntu);
"TV" = LG OLED65C1PTB, webOS 6.5.3, aarch64 art_standalone run by the probe app. No plugin was modified;
each run checks the plugin's SHA-256 before and after.

## How plugins are run

`runtime/csloader` follows CloudStream's `PluginManager.loadPlugin` (PathClassLoader on the .cs3,
manifest.json through CloudStream's Jackson mapper, loadClass/newInstance, `load(Context)` or `load()`,
providers from `APIHolder`), with the unmodified CloudStream pre-release APK (built from `eb962b4`) as
parent class path and `runtime/android-compat` providing the Android framework classes these paths reach.

## Supported classes of plugins

| Class | Status | Why |
|---|---|---|
| `BasePlugin`, no resources | supported | no Android framework needed beyond the compat layer |
| `Plugin` (Context) whose UI is guarded by `context is Activity` | supported | the compat Context is an application context; guarded UI never runs (e.g. CNCVerse donation dialog) |
| `Plugin` that casts the context to `AppCompatActivity` in `load()` | **unsupported** | needs a live Android Activity; reported as NEEDS-ACTIVITY |
| `requiresResources` (Android resources from the .cs3) | **unsupported** | no resource table/AssetManager; reported as `unsupported` event |
| Plugins whose operations use `android.webkit.WebView` (7 CNCVerse plugins reference it) | unsupported when reached | no browser engine in the runtime; would fail with `Unsupported` at that call |
| Settings screens (`openSettings`) | unsupported | Android views; settings must be offered by the native app instead |
| Native `.so` in plugins | none seen | |

## Provider operations

Operations were run only for plugins whose sources are openly licensed or public platforms:
Dailymotion and InternetArchive (official CloudStream repository) and LibriVoxAudiobook (public-domain
audiobooks, CNCVerse repository). Providers that scrape unlicensed copies of films, TV, paid streaming
services or live sports were not exercised beyond the load-only pass.
